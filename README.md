# L'Incognito

A local web app lobby for the game *L'Incognito*. Players can create or join a room, get anonymous pseudos, and chat in the lobby.

## Run locally

1. Node.js is required
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3000` in your browser

## Features

- Create a lobby as the host
- Join a lobby with a 4-letter room code
- Up to 10 players per lobby
- Anonymous pseudonyms for players
- Shared lobby chat
- Questions from a pool are posées en chat
- Nouvelle question après 60s ou lorsque tous ont répondu
